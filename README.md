# 🤖 AI Resume Analyzer

**Analyze. Improve. Get Hired.**

An AI-powered Resume Analyzer built with **Python, Flask, HTML, CSS, and JavaScript** that evaluates resumes, calculates an ATS-style score, detects technical skills, identifies missing keywords, and provides actionable improvement suggestions.

## 🎯 What This Project Does

This tool helps job seekers analyze their resumes and understand how well they align with modern ATS (Applicant Tracking System) expectations.

The analyzer checks:

- Resume structure
- Skill presence
- Important recruiter keywords
- Contact information
- GitHub / LinkedIn visibility
- Project and experience relevance

## ⚙ Installation

Clone repository:

```bash
git clone https://github.com/ayush2614/ai-resume-analyzer.git
```

Go to folder:

```bash
cd ai-resume-analyzer
```

Create virtual environment:

```bash
python -m venv venv
```

Activate:

### Windows
```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open:

```bash
http://127.0.0.1:5000
```
